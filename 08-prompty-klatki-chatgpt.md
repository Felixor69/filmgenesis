# Prompty do pierwszych klatek (ChatGPT)

Gotowe do wklejenia prompty na **pierwsze klatki** ujęć AI z trailera. Każda klatka to początek ujęcia: potem wgrywasz ją do Veo (tryb obraz → wideo) z promptem ruchu z [03-prompty-ai-wideo.md](03-prompty-ai-wideo.md).

## Jak pracować

1. **Jedna rozmowa w ChatGPT na cały trailer.** Zaczynasz od wiadomości startowej (niżej), a potem wklejasz prompty po kolei. ChatGPT pamięta styl i postacie z wcześniejszych obrazów w tej samej rozmowie, więc ujęcia są spójniejsze.
2. **Najpierw arkusze postaci (krok 1)**, potem ujęcia. Przy ujęciach z tymi postaciami dopisz: „użyj postaci z arkusza”.
3. **Referencja z gry.** Tam, gdzie jest napisane 📎, dołącz do wiadomości screenshot z gry (model rasy, portal, Jeździec). ChatGPT dopasuje kolory i kostium, a match cut z gameplayem będzie działał.
4. **Format:** każdy prompt prosi o obraz poziomy 16:9. Jeśli ChatGPT zwróci 3:2, przytnij go do 16:9 albo dopisz: „rozszerz kadr do 16:9”.
5. **Poprawki** rób krótkimi wiadomościami w tej samej rozmowie, np. „to samo, ale ciemniej, postać bardziej w lewo”, zamiast generować wszystko od nowa.
6. **Wersje pionowe (9:16)** do TikToka: po zaakceptowaniu klatki napisz „ta sama scena w pionie 9:16, postać na środku”.

## Wiadomość startowa (wklej jako pierwszą)

```
We are creating keyframes for a dark fantasy game trailer for "Genesis", set in the world of Eldoria.
Every image you generate in this conversation must follow this style unless I say otherwise:

- dark high-fantasy, painterly cinematic realism, like a still frame from a high-budget fantasy film
- nights are deep blue-black; the main light sources are glowing golden souls (small floating orbs
  of warm light) and sacred relics
- palette: warm gold light (#E8B04A) against cold teal-black shadows (#0B1A24), mist and drifting
  light motes, volumetric light
- anamorphic widescreen look, shallow depth of field, subtle film grain
- grounded medieval fantasy, no modern elements
- NO text, NO letters, NO logos, NO watermarks, NO UI
- always landscape 16:9 format

Reply only "OK" and wait for my first image request.
```

## Krok 1: arkusze postaci

### Wojownik z Przystani (początek)
```
Character reference sheet on a plain dark grey background: a young adult warrior shown three times,
front view, side profile and three-quarter view, full body. Short dark hair, determined grey eyes,
small scar on the left cheek. Brand-new plain steel breastplate that looks slightly too light for
them, a round shield polished and spotless, a simple sword. Neutral lighting so details are clear.
Same person in all three views.
```

### Wojownik (koniec, legenda)
```
Using the exact same warrior from the previous sheet (same face, hair and scar), create a new
character reference sheet: now older and battle-hardened, wearing battle-worn dark steel armor,
a dented shield with a painted crest, a deep teal cloak, and a small glowing relic hanging at the belt.
Front, side and three-quarter views, full body, plain dark grey background.
```

### Mag z Przystani
```
Character reference sheet on a plain dark grey background: a young adult mage, slim, curly auburn hair,
shy smile, wearing a long travel coat with far too many pockets, turning a small flickering crystal
between the fingers. Front, side profile and three-quarter view, full body. Same person in all views.
```

### Rasy (Pół-Anioł, Pół-Demon, Nieumarły) 📎
Dołącz obrazek modelu rasy z folderu [referencje/rasy/](referencje/rasy/) (pobrane z wiki Genesis) albo własny screenshot z gry.

Wygląd modeli z wiki (warto trzymać się go w AI):
- **Pół-Anioł:** długie srebrne włosy, złocista skóra, **ciemne, srebrno-szare pierzaste skrzydła**
- **Pół-Demon:** oliwkowo-szara skóra pokryta **świecącymi czerwonymi wzorami**, małe zakręcone rogi, długie srebrnobiałe włosy
- **Nieumarły:** blada, szara, wychudzona skóra, widoczne żebra, długie białe włosy
```
Character reference sheet based on the attached in-game character: create a realistic cinematic
version of this [HALF-ANGEL / HALF-DEMON / UNDEAD] keeping the same colors, clothing and silhouette
as in the screenshot. Front, side and three-quarter views, full body, plain dark grey background.
```
